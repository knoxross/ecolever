## 2. '자연스러움' 기준이 영상뚝딱에 들어간 방식

| 기준 | 넣은 방법 |
|---|---|
| 실사 사진·영상이 화면의 80% 이상 | `tools/brand-kit.js` 가 화면 시간 대비 실사 비율을 계산하고, 80% 미만이면 출력 전에 멈춤. 휴대폰·카드 틀 안 사진은 절반만, 글자 화면은 0으로 셈 |
| 도형·모션그래픽은 자막·로고 정도만 | natural 프리셋이 움직이는 배경·이모지·스티커·효과(번쩍임 등)를 자동으로 뺌. 자막은 아래쪽 작은 명조 |
| 어쿠스틱·잔잔한 음악 | 기본 음악을 `acoustic`(핑거피킹 기타·업라이트 베이스·현악)으로, 음량 0.55 |
| 대사·자막 있을 때 음량 낮춤(덕킹) | 목소리(TTS·녹음) 구간마다 배경음악을 30%로 자동으로 낮춤(기존 기능). 녹음 파일도 같은 방식 |
| 끝은 페이드아웃 | 마지막 약 2.5초 동안 자동으로 페이드아웃(기존 기능) |
| 저작권 해결 음원·출처 기록 | 자체 작곡은 저작권이 없고, 문구와 history 에 '음악: 영상뚝딱 자체 작곡'으로 기록. 외부 음원은 `music.file` + `upload.source` 에 출처 |
| 컷 2~4초, 화려한 전환·효과음 없음 | natural 프리셋이 길이를 2~4초로 맞추고, 전환은 바로/페이드만. 검사기도 다시 확인 |
| 사람 목소리에 가까운 TTS 또는 대표님 녹음 | 구글 TTS(키 필요) 또는 장면별 `"voice": "녹음.m4a"` |
| 한 영상 = 한 브랜드 | 브랜드 키트·섞임 검사(11/24) 그대로 |
