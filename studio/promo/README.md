## 하루 작업 순서
1. **브랜드 고르기**: `history.json` 의 마지막 브랜드와 다른 쪽.
2. **트렌드 확인**: 웹 검색으로 이번 주 숏폼 포맷·밈·시즌 이슈를 확인한다.
   - 브랜드에 맞는 것만 쓴다. 억지 밈이나 남의 음원·캐릭터는 쓰지 않는다.
3. **기획** (`brands.json` 의 톤·사실·금지사항을 지킨다):
   - 첫 1초 훅
   - 3~6장면, 장면당 2~3.5초
   - 마지막 화면은 행동 유도 + 연락처나 주소
   - 같은 주제를 반복하지 않도록 `history.json` 의 주제를 확인한다.
4. **작업 파일 쓰기**: `jobs/<날짜>-<브랜드>/` 아래에 `shorts.json`(9:16), `feed.json`(1:1), `caption.md`(올릴 문구).
5. **만들기**:
   `node tools/ttuk-make.js promo/jobs/<날짜>-<브랜드>/ -o ../deliver/promo/<날짜>-<브랜드>`
6. **검수**:
   - 결과 JSON 의 qa 와 장면별 화면을 직접 확인한다.
   - 확인할 것: 글자 잘림, 오탈자, 사실 오류.
   - 문제가 있으면 고쳐서 다시 만든다.
7. **전달**:
   - 사용자에게 영상·문구를 보낸다(SendUserFile).
   - 표지·문구는 구글 드라이브 '영상뚝딱 홍보물/<브랜드 폴더>'에도 올린다. 한 번에 약 3MB까지라 영상은 올라가지 않는다.
   - 사용자 PC 저장 위치: 에코레버 → `C:\Work\ecolever\홍보동영상`, 지마당 → `C:\Work\gmadang\지마당 동영상홍보`. PC 폴더 연결이 되면 그곳에 저장한다.
   - `history.json` 에 기록하고, 커밋·푸시한다.

## 화면 원칙 — 실사·영화 같은 고퀄리티 (2026-11-16 사용자 요청)
- 만화·그림·그래픽 느낌 말고 **실제 영상·실제 화면처럼**.
- 소재 우선순위:
  1. 실제 촬영 영상·사진 (`assets/<브랜드>/footage/`, `model/` 김국화 대표)
  2. AI 실사 영상·사진 (구글 키가 있을 때 Veo·Imagen, 'photorealistic, cinematic, 35mm' 지시)
  3. 실제 사이트 화면 캡처
- 이모지·스티커·움직이는 그래픽 배경(aurora·bokeh·rays·grid)은 쓰지 않거나 최소로 쓴다.
- 글자는 영화 자막처럼 작고 단정하게. 영상 색감은 필름 톤으로(filter: film·warm, fx: grain·cinema·leak 약하게).

## 음악 원칙 — 영상과 함께 움직이는 음악 (2026-11-16 사용자 요청)
- 한 곡 내내 잔잔하거나, 내내 웅장하거나, 내내 시끄러우면 안 된다. **장면의 감정 흐름을 따라 음악이 바뀐다.**
- 장면마다 에너지(0 고요 ~ 3 절정)와 분위기를 기획에 적고, 영상뚝딱 작곡기가 그 흐름대로 편곡한다(영상 맞춤 작곡).
  - 0초 훅: 귀를 잡는 첫소리. 예: 뚝 끊긴 정적 뒤 한 방, 또는 궁금증을 만드는 긴장음.
  - 문제·공감 장면: 작게, 악기 수를 줄이기.
  - 반전·공개 직전: 상승음(라이저)과 드럼 채우기, 직후 '드롭'(전 악기)이나 0.3초 정적.
  - 정보 장면: 박자는 유지하고 멜로디는 비켜 주기. 자막이 읽히게.
  - 마지막 행동 유도: 가장 밝고 큰 부분에서 으뜸화음으로 깔끔하게 끝내기.
- 화면 전환 순간에 박·강세를 맞춘다(장면 길이를 박자 단위로).
- 실제 악기 소리, 사람이 연주한 듯한 미세한 흔들림, 자연스러운 잔향. 기본 파형 소리는 쓰지 않는다.
- 브랜드 결: 에코레버는 따뜻한 어쿠스틱(기타·피아노·현악), 지마당은 밝은 동네 아침(피아노·우쿨렐레·박수, 뉴스 느낌 리듬).

## 영상 맞춤 작곡 사용법 (2026-11-17 추가)
- spec.json 장면마다 `"energy": 0~3`, `"hit": true`(크래시·한 방), `"musicStop": true`(직전 0.3초 정적)을 적는다. 적지 않으면 자동으로 훅 강하게 → 가운데 숨 고르기 → 끝으로 고조.
- 실사 느낌: `"emoji": false`(자동 이모지 끔), `"filter": "cine"`(영화 색감), `"fx": "grain"`, `"font": "serif"`, 사진은 `"fit": "blur"`(사진 전체 + 흐린 배경) + 느린 zoomIn/zoomOut.

## 영상뚝딱으로 쓰는 홍보물 기법
- `fit: "phone"` + `motion: "scrollDown"`: 사이트·앱 화면을 휴대폰 틀 안에서 스크롤 (`assets/*/site-*.png`)
- `fit: "card"`: 제품 사진을 브랜드 색 배경 위 카드로 (흰 배경 제품 사진에 좋음)
- `fx`: punch(강조), flash(전환), shake(놀람), sparkle(반짝)
- `sticker`: 장면 오른쪽 위 이모지
- `endcard`: 마지막 화면에 QR·문구
- `logo`: 워터마크
- 음악: 직접 작곡(저작권 없음). 에코레버는 corp·luxury·lofi, 지마당은 bright·corp·cute.
