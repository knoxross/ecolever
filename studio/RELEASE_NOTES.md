- 홍보물 도구: `--only wide`처럼 원하는 비율만 다시 만들 수 있습니다. 올릴 문구(caption.md)에는 이미 만든 다른 비율 파일도 그대로 적힙니다.

## 캡컷과 비교해서 바뀐 점 (2.3.0)
쓰는 방식과 결과물 수준을 캡컷과 비슷하게 맞췄습니다. 이름·로고·화면 디자인·효과 자산은 가져오지 않았습니다.

**1. 3단계로 만들기 (처음 쓰는 사람용)**
- ⚡ 3단계로 만들기: ① 사진·영상 고르기(끌어다 놓기 가능) → ② 템플릿 고르기 → ③ 자막·음악이 붙은 미리보기를 바로 재생 → ⬇ 동영상 저장
- 템플릿: 브랜드·상품 소개 / 정보·안내 / 행사·모집 / 일상·브이로그
- 영상 하나에는 브랜드 하나만 넣습니다(이름·색·로고·사이트). 회사는 끝 화면 아래 한 줄로 적을 수 있습니다.
- 화면 비율 9:16·1:1·16:9를 고르면 사진이 자동으로 맞춰집니다(잘림 없이 흐린 배경).
- 🔽 간단히 보기 / 🛠 고급 편집 펼치기: 타임라인(자르기·순서·속도·자막·음량)은 펼쳐서 씁니다.

**2. 자연스러움 기준**
- 실사 사진·영상 위주로 만듭니다. 기획서 검사에서는 실사 화면이 80% 미만이면 멈춥니다.
- 그래픽은 자막과 로고 정도만 씁니다.
- 전환은 바로 넘기기와 페이드만 씁니다. 효과음은 없습니다. 컷은 2~4초입니다.
- 음악: 새 '어쿠스틱(통기타 핑거피킹)' 결을 넣었습니다. 음량은 낮게 두고, 끝은 페이드아웃합니다. 직접 작곡한 음악이라 저작권 걱정이 없습니다.
- 목소리: 자막을 자연스러운 AI 목소리로 읽을 수 있습니다(구글 키 필요). 말할 때는 음악이 자동으로 작아집니다(덕킹). 녹음 파일도 장면마다 넣을 수 있습니다.
- 자동 자막: 영상 속 말소리를 받아써서 자막으로 만듭니다(구글 키 필요).

**3. 그 밖**
- 체크리스트 장면, 숫자 카운트업, '광고' 표시 배지, 브랜드 섞임 검사가 추가됐습니다.

아직 없는 것: 배경 제거(다음 단계), 키 없이 쓰는 음성 인식·TTS(검토 중).

## 2.3.1
- 한 기획에서 9:16(쇼츠·릴스·스레드)·4:5(인스타 피드)·16:9(네이버 블로그) 세 가지를 한 번에 만듭니다(홍보 도구).
