# 영상뚝딱 — 사진 넣고 명령어 한 줄이면 완성되는 홍보 영상 제작기

윈도우(.exe 설치) · 맥(.dmg) · 안드로이드(.apk) 앱. 메뉴·안내·진행 표시는 모두 한국어입니다.

## 설치

- **윈도우**: `YeongsangTtukttak-…-win-x64.exe` 실행 → 설치 폴더 선택 → 바탕화면/시작 메뉴에 '영상뚝딱' 생김.
  *인증서 서명이 없어서 처음에 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.*
  삭제: 설정 → 앱 → 영상뚝딱 → 제거 (또는 제어판 → 프로그램 제거).
- **맥**: `.dmg` 열기 → 영상뚝딱을 Applications 로 끌어놓기. 처음 실행 때 막히면 앱을 **우클릭 → 열기**.
  삭제: Applications 에서 휴지통으로.
- **안드로이드**: `.apk` 를 휴대폰에 받아 설치 ("출처를 알 수 없는 앱" 허용 필요). 삭제: 앱 아이콘 길게 누르기 → 제거.

## AI 키 (선택)

키가 없어도 기본 자동편집·녹음·화질 향상·저장은 모두 됩니다.

| 키 | 쓰는 곳 | 발급 |
|---|---|---|
| Claude API 키 | 사진 보고 자동 편집, 자막·내레이션 쓰기, 업로드 문구, 한국어 설명 번역 | https://console.anthropic.com/settings/keys |
| Google AI 키 | 사람·물건 사진 생성, 영상 생성, AI 성우 | https://aistudio.google.com/apikey (영상 생성은 결제 등록 필요할 수 있음) |

키는 이 기기에만 저장됩니다 (데스크톱은 운영체제 암호화 저장소 사용).

## 고도화 (기능 추가·수정·제거 주문)

- **기능 켜고 끄기**: `www/js/config.js` 의 `FEATURES` 에서 `true/false` 만 바꾸면 해당 버튼·메뉴·창이 사라지거나 나타납니다 (예: `schedule: false`).
- **회사 정보·버전**: 같은 파일의 `BRAND`, 그리고 `package.json` 의 `version`.
- **새 버전 배포**: 버전 올림 → `npm run dist:win` → `bash scripts/deploy-update.sh` → 설치된 PC가 자동 업데이트.
- 기능별로 파일이 나뉘어 있어(아래 구조) 원하는 부분만 고칠 수 있습니다.

## 개발자용: 직접 빌드하기

```bash
cd studio
npm ci
npm start              # 데스크톱 앱 실행 (개발)
npm run dist:win       # 윈도우 설치 파일 → dist/*.exe  (리눅스에서는 wine 필요)
npm run dist:mac       # 맥 앱 (맥에서만)
npm run android:apk    # 안드로이드 APK (Android SDK 필요)
```

GitHub 에서는 **Actions → 영상뚝딱 앱 빌드 → Run workflow** 를 누르면 세 가지 설치 파일이 한 번에 만들어집니다.
`ttuk-v1.0.1` 처럼 태그를 올리면 Releases 에 자동으로 올라갑니다.

```
    js/generate.js    Google: 사진·영상 생성, AI 성우

    js/scheduler.js   예약 만들기
    js/pipeline.js    제작 공정 (사진 없이 만들기 · 점검 → 저장 → 검수)

    js/qa.js          자동 검수
    js/ui.js          화면 연결
  electron/       데스크톱 앱 (한국어 메뉴, 파일 저장, 키 보관)
  android/        안드로이드 앱 (Capacitor)
```
