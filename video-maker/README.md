# 동영상 제작기

브라우저만으로 사진·동영상·자막·배경음악을 합쳐 영상 파일(MP4/WebM)을 만드는 도구입니다.
설치나 서버가 필요 없고, 올린 파일은 외부로 전송되지 않고 내 컴퓨터(브라우저) 안에서만 처리됩니다.

## 실행
- 사이트에 올린 뒤: `https://www.ecolever.co.kr/video-maker/`
- 내 컴퓨터에서: 저장소 폴더에서 `python -m http.server` 실행 후 `http://localhost:8000/video-maker/` 접속
- **Chrome 또는 Edge 최신 버전**을 권장합니다 (MP4 저장 지원).

## 사용 방법
1. **📁 파일 추가** 또는 파일을 화면에 끌어다 놓기 — 사진·영상은 타임라인에, 음악은 배경음악으로 자동 등록됩니다.
   파일 이름에 `logo`/`로고`가 들어간 이미지는 워터마크 로고로 등록됩니다.
2. 타임라인에서 클립을 클릭해 **길이, 시작 지점, 화면 맞춤, 확대 효과, 전환 효과, 자막**을 편집합니다.
   클립을 끌어서 순서를 바꿀 수 있습니다.
3. **프로젝트** 탭에서 화면 비율(16:9 / 9:16 쇼츠 / 1:1 / 4:5), 화질, 배경음악 볼륨, 로고 위치를 정합니다.
4. **⬇ 동영상 만들기** → 영상 길이만큼 실시간 녹화 후 다운로드 버튼이 나타납니다.
   녹화 중에는 탭을 바꾸지 마세요.

## 단축키
- `Space` 재생/일시정지 · `←/→` 0.1초 이동 (`Shift`와 함께 1초) · `Delete` 선택 클립 삭제 · `Home` 처음으로
