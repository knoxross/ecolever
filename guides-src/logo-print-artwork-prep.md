## 로고 인쇄는 "파일"에서 시간이 갈립니다
견적과 수량이 정해져도 로고 파일이 맞지 않으면 시안 수정이 반복됩니다. 처음부터 인쇄에 맞는 파일을 보내면 시안 확정이 훨씬 빨라집니다.

## 1. 어떤 파일을 보내야 하나
- **가장 좋은 파일:** AI(일러스트레이터) 또는 PDF 같은 벡터 파일. 크기를 키워도 깨지지 않습니다.
- **차선:** 배경이 투명한 고해상도 PNG
- **피해야 할 파일:** 홈페이지나 메신저에서 저장한 작은 이미지, 캡처 화면, 배경이 흰색으로 채워진 JPG
- 기관·기업에 **CI 가이드(로고 사용 규정)** 가 있다면 함께 보내 주세요. 색상과 여백 규정을 지킬 수 있습니다.

## 2. 위치와 크기 정하기
- 한 면에만 넣을지, 양면에 넣을지 먼저 정합니다.
- 가방 정면 중앙이 가장 잘 보이지만, 원단 무늬가 있는 경우 무늬와 겹치는 정도를 시안으로 확인합니다.
- 로고 아래에 캠페인 문구나 웹사이트 주소를 넣고 싶다면 이때 함께 알려주세요.

## 3. 색상 수 정하기
- 인쇄 색상 수가 늘어날수록 작업이 복잡해질 수 있습니다. 인쇄 방식과 색상 수는 로고와 수량에 맞춰 업체와 협의합니다.
- 원단 바탕색과 로고 색의 대비가 충분한지 확인합니다. 밝은 원단에 연한 색 로고는 잘 보이지 않을 수 있습니다.

## 4. 시안 확인할 때 볼 것
- 로고 철자, 기관명·회사명 표기
- 로고 크기와 위치가 실제 가방 비율에서 적절한지
- 색상이 CI 규정과 맞는지
- 문구·웹사이트 주소에 오타가 없는지

시안을 승인한 뒤에 생산이 시작되므로, 내부 결재가 필요한 경우 시안 단계에서 미리 확인받는 것이 좋습니다.

## 5. 수량과 일정
- 로고 인쇄는 인쇄 공정이 추가되어 최소 수량이 커집니다.
- 행사일 → 납품일 → 생산 → 시안 확정 → 로고 파일 전달 순서로 거꾸로 일정을 잡습니다.

## 에코레버의 경우
에코레버의 로고 인쇄 주문은 **10,000개부터** 진행합니다(로고 인쇄 없는 주문은 100개부터). 로고 파일(AI·PDF·고해상도 PNG)을 보내주시면 인쇄 시안을 만들어 확인받은 뒤 생산하며, 인쇄 방식과 색상 수는 로고와 수량에 맞춰 협의합니다. 원단은 FITI 시험성적서 기준 면 85.2% · 황마 10.9% 혼방, 사이즈는 40×37cm(손잡이 40cm)입니다. [견적 문의하기](/#inquiry)
